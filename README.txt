SUBA — A Little Birthday Universe
=================================

HOW TO OPEN
1. Extract the ZIP folder.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Double-click index.html to open it in Chrome or Edge.
4. Tap ENTER YOUR MAGIC once. Browsers require a user gesture before background music can autoplay.
5. Enter the password: SUBA

AUDIO BEHAVIOUR
- Main background track loops through the experience.
- Opening either special photo pauses the main track and plays that photo's song.
- Closing the special-photo viewer stops its song and resumes the main track.
- The voice message pauses the main track and resumes it when playback ends.
- Voice-message plays are counted in this browser's localStorage. After two plays, the voice section disappears on this browser.

IMPORTANT NOTES
- The birthday album contains four photos; tap a photo to open it and use arrows to browse.
- The Cute Message section shows one photo at a time with arrows and touch-swipe support.
- The A Little Surprise letter and two special photos are separate from the birthday letter and album.
- The microphone candle option needs microphone permission and a secure context (for example, GitHub Pages HTTPS). The pink button always works as a manual fallback.
- Browser storage is local to each browser/device. The two-play limit is not shared between phone and PC, and clearing browser site data can reset it.
- GitHub Pages repositories are public. Anyone with the site URL can view/download the included images and audio files. Do not upload private files if that is a concern.
- The Birthday Letter currently uses temporary sample wording; replace it with the final letter if you want different text.
- This is a first working draft and still needs a visual/browser test pass before sharing.
